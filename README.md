# E-commerce Sales & Profitability Intelligence

An end-to-end analytics project: data cleaning, a star-schema SQL database, Python EDA, a reconciled KPI layer and a Power BI specification, built to answer *where does an e-commerce business make and lose money?*

> **The data is SYNTHETIC.** It is generated by `src/generate_synthetic_data.py` and does not describe any real company. Findings demonstrate method, not real-world facts.

## Headline results (synthetic data, 2022-2025)
Revenue **USD 3,738,533** · profit **USD 700,783** · margin **18.7%** · 3,895 orders · 33,100 units · average order value USD 959.83.

* Tables, Bookcases and Machines bring 27.8% of revenue and lose USD 70,422.
* Central region: 19.4% of revenue, margin 11.6% against 20.5% elsewhere; 53% of its lines are discounted.
* Margin is 32.1% with no discount and negative from the 21-30% discount band. Lines discounted over 30% lost USD 190,989.
* 14 of the 44 top-revenue-quartile products earn under 10% margin.
* November and December carry 26.9% of annual revenue.

Full evidence: `reports/business_insights.md`.

## Quick start (Windows PowerShell)
```powershell
git clone <your-repo-url>; cd ecommerce-sales-profitability-intelligence
python -m venv .venv; .venv\Scripts\Activate.ps1
pip install -r requirements.txt
python src\run_pipeline.py --regenerate     # data > clean > star schema > SQL > reconcile > insights
python tests\test_pipeline.py               # 7 tests
jupyter notebook notebooks\ecommerce_eda.ipynb
```
If activation is blocked: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.

**PostgreSQL (optional):** create a database, then
`psql -U postgres -d ecommerce_bi -f sql/schema.sql` and `psql -U postgres -d ecommerce_bi -f sql/load_data_postgres.sql` (run from the project root), then run `sql/data_quality_checks.sql` and `sql/business_analysis.sql`.

**Power BI:** follow `powerbi/power_query_load.md`, `powerbi/dax_measures.md`, `powerbi/dashboard_design.md`; verify with `powerbi/expected_kpis.csv`.

## Troubleshooting
| Problem | Fix |
|---|---|
| `pip` or `python` not recognised | Reinstall Python with "Add to PATH" ticked, or use `py -m pip` |
| `psycopg2` build error | Use `psycopg2-binary` (already in requirements) |
| `psql` not found | Add `C:\Program Files\PostgreSQL\16\bin` to PATH |
| `\copy` cannot find files | Start `psql` from the project root; paths are relative |
| Power BI shows `4.0` or wrong decimals | Use the `"en-US"` culture in the M code |
| Postal codes lose leading zeros in Excel | Import the column as Text |
| `UnicodeDecodeError` on a real dataset | Set `$env:RAW_ENCODING = "latin-1"` |

## Limitations
Synthetic data; no cost, return-reason or inventory fields; one country; discount findings are associations, not proven causes. Details in `docs/methodology.md`.
